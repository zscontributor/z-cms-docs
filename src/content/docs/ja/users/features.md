Z-CMS では、1 つのシステムで複数の Web サイトを管理できます。データと設定はサイトごとに分離されます。管理画面に表示される機能は、アカウントのロールと選択中のサイトによって異なります。

| 画面 | 主な操作 | ガイド |
| --- | --- | --- |
| Sites | サイト作成、ホスト名、ブランド、公開状態の管理 | [複数サイトの管理](/ja/users/sites/) |
| Content（コンテンツ） | ページやブログ記事の作成、ブロックの配置、翻訳、プレビュー、公開 | [コンテンツの作成と公開](/ja/users/content/) |
| Media | アップロード、検索、フォルダー整理、代替テキスト編集 | [画像とファイルの管理](/ja/users/media/) |
| Marketplace | 署名済みパッケージの検索とインストール | [テーマとプラグイン](/ja/users/extensions/) |
| Appearance（外観） | テーマの有効化、設定フォームの入力、サンプルデータの作成 | [外観とテーマ設定](/ja/users/appearance/) |
| Users / Profile | 招待、ロール、パスワード、2FA | [ユーザーと権限、アカウントの保護](/ja/users/users-security/) |
| Settings → Mail | SMTP 設定とテスト送信 | [メールとバックグラウンドジョブ](/ja/users/operations/) |
| Jobs | 失敗したジョブの確認と再実行 | [メールとバックグラウンドジョブ](/ja/users/operations/) |
| zAI | 自然言語によるページやブログ記事の管理 | [zAI によるコンテンツ管理](/ja/users/zai/) |

## 変更対象を確認する

コンテンツ、メディア、外観、プラグイン、メール設定の変更は、現在選択しているサイトに適用されます。一方、**Sites** 画面には、アカウントがアクセスできるすべてのサイトが表示されます。必要なメニューや操作ボタンが見つからない場合は、不具合と判断する前に、選択中のサイトと自分のロールを確認してください。

## バックグラウンドで行われる処理

ワーカー（バックグラウンド処理用のプロセス）は、サイズ違いの画像の生成、メール送信、サイトマップの更新、プラグインのフック処理を担当します。Marketplace は失効したパッケージの情報を同期します。監査ログには、zAI 経由の操作を含むセキュリティイベントと重要な操作が記録されます。
