Z-CMS の管理画面（Admin）では、コンテンツ、画像やファイル、テーマ、プラグイン、サイトのメンバーをまとめて管理できます。

:::note[技術用語の表記について]
コマンド名、API 名、設定フィールド名は、製品と照合できるよう原文のまま記載します。画面名やボタン名は英語表記を基本とし、必要に応じて日本語の説明を添えます。「テーマ」はサイトの表示を定義するパッケージ、「プラグイン」は機能を追加する拡張機能を指します。
:::

## ログイン

導入済みの環境では、サイトのドメインに `/admin` を付けた URL を開きます（例: `https://your-site.com/admin`）。ローカル開発環境では、管理画面は別のポートで動作するため、`http://localhost:3101` にアクセスしてください。初期サンプルデータを使用している場合は、メールアドレス `admin@z-cms.org`、パスワード `admin123` でログインできます。二要素認証を有効にしている場合は、認証アプリに表示されるコードも入力します。

## 最初のステップ

1. **Settings**（設定）でサイト名、タイムゾーン、言語を確認します。
2. **Content**（コンテンツ）を開き、最初のコンテンツを作成します。
3. **Media**（メディア）に画像をアップロードします。
4. **Appearance**（外観）でメニューと使用中のテーマを確認します。
5. **Users**（ユーザー）でメンバーを招待し、業務に必要な最小限のロールを割り当てます。

:::tip
**Administrator** ロールは、サイト全体を管理する必要があるユーザーにのみ割り当ててください。
:::
