zAI Content Operator を使うと、普段の言葉で指示するだけでページやブログ記事を管理できます。zAI が実行できるのは、現在のアカウントに許可された操作だけです。すべての操作は Z-CMS API を経由し、権限の確認と監査ログへの記録が行われます。

## 対応する操作

- ページやブログ記事の一覧表示と検索。
- 下書き（Draft）の作成。
- タイトル、スラッグなど対応フィールドの編集。
- コンテンツの公開と非公開への変更。
- 明示的な確認後の削除。

## 正確な指示を書く

指示には、コンテンツタイプ、状態、言語、変更する値を含めてください。例:

```text
「メンテナンスのお知らせ」というタイトルで、日本語のブログ記事の下書きを作成してください。スラッグは「maintenance-notice」にしてください。
```

```text
タイトルに「サービス」を含む公開中のページを一覧表示してください。
```

操作後は **Content** を開き、特にスラッグ、言語、内部リンク、SEO フィールドを確認してください。

## 削除操作

削除を依頼すると、zAI は処理を一時停止し、**Confirm deletion**（削除の確認）を表示します。確定する前に対象をもう一度確認してください。検索結果だけでは削除対象を特定できない場合は、操作をキャンセルします。

:::caution
会話にはシークレット、認証情報、機密性の高い個人情報を入力しないでください。zAI はコンテンツ操作を支援する機能であり、編集・承認手続きの代わりにはなりません。
:::

権限不足と表示された場合は、必要な権限を持つアカウントを使うか、Editor または Admin に操作を依頼してください。一度の作業のために、必要以上の権限を付与しないでください。
