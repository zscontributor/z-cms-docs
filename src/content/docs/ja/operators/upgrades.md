アップグレード前にリリースノートを読み、テーマとプラグインの互換性を確認します。復元テスト済みのバックアップを用意し、問題が起きたときに以前のバージョンへ戻せる状態を保ってください。

## 推奨手順

1. 機密情報を削除またはマスキングした本番データのコピーで、新しいバージョンをテストします。
2. ステージング環境でデータ移行を実行し、主要機能が動くか確認します。
3. 移行手順で必要とされる場合は、データ構造の変更を一時停止します。
4. リリースノートに記載された順序で各コンポーネントを配置します。
5. API の稼働状態、キュー、サイトの表示、監査ログを確認します。
6. 以前のバージョンに戻すための保持期間が終わってから、旧バージョンのリソースを削除します。
