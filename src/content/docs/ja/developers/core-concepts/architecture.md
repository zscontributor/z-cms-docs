Z-CMS は、API、公開サイトの表示処理、管理画面、プラグインの実行基盤、ワーカーを、それぞれ独立したプロセスで動かします。

## コンポーネント

| コンポーネント | 役割 |
| --- | --- |
| `cms-api` | 認証、ロールベースのアクセス制御（RBAC）、コンテンツ・メディア管理、Marketplace、表示用 API |
| `site-runtime` | 使用中のテーマによる公開サイトの表示 |
| `admin-web` | 管理画面の提供 |
| `plugin-runtime` | 認証情報を保持せず、V8 の隔離環境でプラグインを実行 |
| `worker` | 画像の変換、メール送信、サイトマップの更新、バックグラウンドジョブの実行 |

## 信頼境界

- PostgreSQL Row-Level Security によって、組織（テナント）ごとにデータを分離します。
- プラグインのコードは API プロセス内では実行しません。
- パッケージは公開者の署名に加え、Marketplace の審査と署名を経て配布されます。インストール時には両方の署名とチェックサムを検証し、署名後の改変を検出します。

これらはプラットフォームが実施する必須のセキュリティ対策です。拡張機能の実装側で省略できるルールではありません。
